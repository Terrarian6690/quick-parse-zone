# Code Converter Hub

I want to build an English-language website that provides free online

tools for converting numbers, text and encoding/decoding messages.

The main idea is to provide tools such as:

- binary to decimal converter

- decimal to binary converter

- hexadecimal converter

- octal converter

- text to numbers

- numbers to text

- text to binary

- binary to text

- ASCII converter

- A1Z26 encoder/decoder

- base-26 converter

- custom number base converter

Before building anything, perform SEO keyword research using your

available Semrush data.

I want you to:

1. Find relevant keywords for these tools.

2. Identify keywords with good search potential and realistic competition.

3. Group the keywords by search intent.

4. Identify the most promising tools/pages to build first.

5. Analyze competitors ranking for the most promising keywords.

6. Identify gaps in the existing search results.

7. Recommend the ideal website structure and URL structure.

8. Recommend the first 10-20 tools I should build.

9. For each recommended page, suggest an SEO title, H1 and meta description.

10. Do NOT create the website yet. Only give me the SEO research and strategy.

Focus primarily on English-speaking markets, especially the United States,

United Kingdom, Canada and Australia.
